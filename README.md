# CS-360
The goal of this app was to address a specific user need by providing a simple, functional mobile solution that allows users to complete key tasks efficiently on a mobile device. The requirements focused on usability, reliability, and clear interaction, ensuring that users could accomplish their objectives without confusion or unnecessary steps.

To support these needs, the app included essential screens and features such as a main interface for core actions, input areas for user data, and feedback elements to confirm successful operations. The UI was designed with simplicity and clarity in mind, using logical navigation, readable layouts, and consistent elements so users could understand how to use the app without prior instruction. These design choices were successful because they reduced cognitive load and kept the focus on the primary task.

My coding approach emphasized organization and incremental development. I implemented features in small sections, testing each part before moving on to the next. This strategy made debugging more manageable and ensured that new changes did not break existing functionality. These techniques are transferable to future projects because they support maintainability and reduce development risk.

Testing involved running the app frequently on an emulator and/or device to verify that each feature worked as expected and that user inputs produced the correct outcomes. This process is important because it identifies errors, edge cases, and usability issues early. Testing revealed minor issues with input handling and navigation that were resolved before finalizing the app.

Throughout the development process, I had to adapt and refine my approach when initial implementations did not behave as expected. This required researching solutions, revising code structure, and adjusting design decisions to maintain usability while meeting technical constraints.

I was particularly successful in implementing the core functionality of the app, where I demonstrated my understanding of both the development framework and user-centered design principles. This component reflects my ability to translate requirements into a working product and highlights the knowledge and skills gained during the project.
